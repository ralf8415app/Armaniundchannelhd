# Pro 20 – Galaxy-Bonus Hochformat

- Das Weltraum-Bonusspiel ist für Hochformat optimiert.
- Startet nur bei hochkant gehaltenem Gerät.
- Im Querformat wird das Spiel pausiert und eine Drehaufforderung angezeigt.
- Nach dem Drehen ins Hochformat läuft das Bonusspiel automatisch weiter.
- Touch-Steuerung: links, rechts, oben, unten und Feuer.
